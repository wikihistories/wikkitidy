# Generate pages that meet certain criteria, or which are related to a set of known pages by certain properties

Many of the endpoints on the Action API can be used as `generators`. Use
`list_all_generators()` to see a complete list. The main advantage of
using a generator is that you can chain it with calls to
[`query_page_properties()`](https://wikihistories.github.io/wikkitidy/reference/query_page_properties.md)
to find out specific information about the pages. This is not possible
for queries constructed using
[`query_list_pages()`](https://wikihistories.github.io/wikkitidy/reference/query_list_pages.md).

## Usage

``` r
query_generate_pages(.req, generator, ...)

list_all_generators()
```

## Arguments

- .req:

  A httr2_request, e.g. generated by `wiki_action_request`

- generator:

  The generator module you wish to use. Most
  [list](https://www.mediawiki.org/wiki/API:Lists) and
  [property](https://www.mediawiki.org/wiki/API:Properties) modules can
  be used, though not all.

- ...:

  \<[`dynamic-dots`](https://rlang.r-lib.org/reference/dyn-dots.html)\>
  Additional parameters to the generator

## Value

query_generate_pages: The modified request, which can be passed to
[next_batch](https://wikihistories.github.io/wikkitidy/reference/get_query_results.md)
or
[retrieve_all](https://wikihistories.github.io/wikkitidy/reference/get_query_results.md)
as appropriate.

list_all_generators: a
[tibble](https://tibble.tidyverse.org/reference/tbl_df-class.html) of
all the available generator modules. The `name` column gives the name of
the generator, while the `group` column indicates whether the generator
is based on a list module or a property module. Generators based on
property modules can only be added to a query if you have already used
[query_by\_](https://wikihistories.github.io/wikkitidy/reference/query_by_.md)
to specify which pages' properties should be generated.

## Details

There are two kinds of `generator`: list-generators and prop-generators.
If using a prop-generator, then you need to use a
[`query_by_()`](https://wikihistories.github.io/wikkitidy/reference/query_by_.md)
function to tell the API where to start from, as shown in the examples.

To set additional parameters to a generator, prepend the parameter with
"g". For instance, to set a limit of 10 to the number of pages returned
by the `categorymembers` generator, set the parameter `gcmlimit = 10`.

## See also

[`gracefully()`](https://wikihistories.github.io/wikkitidy/reference/gracefully.md)

## Examples

``` r
# Search for articles about seagulls
seagulls <- wiki_action_request() %>%
  query_generate_pages("search", gsrsearch = "seagull") %>%
  gracefully(next_batch)
```
