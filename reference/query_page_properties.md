# Choose properties to return for pages from the action API

See [API:Properties](https://www.mediawiki.org/wiki/API:Properties) for
a list of available properties. Many have additional parameters to
control their behavior, which can be passed to this function as named
arguments.

## Usage

``` r
query_page_properties(.req, property, ...)

list_all_property_modules()
```

## Arguments

- .req:

  A httr2_request, e.g. generated by `wiki_action_request`

- property:

  The property to request

- ...:

  \<[`dynamic-dots`](https://rlang.r-lib.org/reference/dyn-dots.html)\>
  Additional parameters to pass, e.g. to modify what is returned by the
  property request

## Value

An HTTP response: an S3 list with class httr2_request

## Details

query_page_properties is not useful on its own. It must be combined with
a
[query_by\_](https://wikihistories.github.io/wikkitidy/reference/query_by_.md)
function or
[query_generate_pages](https://wikihistories.github.io/wikkitidy/reference/query_generate_pages.md)
to specify which pages properties are to be returned. It should be noted
that many of the
[API:Properties](https://www.mediawiki.org/wiki/API:Properties) modules
can themselves be used as generators. If you wish to use a property
module in this way, then you must use
[query_generate_pages](https://wikihistories.github.io/wikkitidy/reference/query_generate_pages.md),
passing the name of the property module as the `genenerator`.

## See also

[`gracefully()`](https://wikihistories.github.io/wikkitidy/reference/gracefully.md)

## Examples

``` r
# Search for articles about seagulls and retrieve their number of
# watchers

resp <- wiki_action_request() %>%
  query_generate_pages("search", gsrsearch = "seagull") %>%
  query_page_properties("info", inprop = "watchers") %>%
  gracefully(next_batch)
if (!is_wikkitidy_failure(resp)) {
  resp <- dplyr::select(resp, pageid, ns, title, watchers)
}
resp
```
